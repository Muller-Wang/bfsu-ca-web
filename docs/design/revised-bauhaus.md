# 再版参考：有秩序的创造力

预览地址：`/revised`。封面、工作台和登录通过顶部分段导航切换。原有页面继续保留。

## 现版观察

现版采用冷灰底色、Geist 无衬线字、居中主标题、粒子连线、胶囊按钮和圆角卡片。整体已经简洁，但封面与内页的视觉关系偏弱；全局浅灰元信息较多，品牌缺少能被记住的形状。

## 再版方向

- 暖白 #F7F6F2、纸灰 #EEEDE7、炭黑 #252521、朱红 #BD4632。红色集中在几何主视觉和少量状态标记。
- 保留现有字体资源；中文标题 500 字重，扩大字号层级，元信息精简为必要日期、分类和章节编号。
- 圆、矩形、拱形及线阵组成品牌符号。图形为原生 CSS，不依赖外部图片。
- 封面改为非对称双栏，主标题“创意，在北外。”保持。下方用线性内容分区承载活动、内容和外联。
- 工作台以一周日程为中心，右侧放公告与常用入口；示例数据与实际业务数据隔离。
- 登录采用图形与表单的对照排版。此页为参考，真实认证仍通过 `/login`。

## 动效

- 页面切换：240ms 淡入并移动 10px；顶部分段滑块使用阻尼弹簧。
- 几何入场：约 1.4s 的错位归位，重播按钮可再次播放。
- 内容进入视口：500ms 淡入，移动 16px，仅一次。
- 按钮悬停：2px 轻微上移，约 250ms；不改变布局。
- 遵循系统减少动态效果设置，并提供“静态浏览”开关。

## 边界

这是一组交互设计参考，不替换正式业务页面。工作台日期、任务和公告为明确标注的示例；任务勾选和筛选仅存在于当前组件状态。原有账号、数据库、鉴权逻辑保持。
